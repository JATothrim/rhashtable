A single header library that implements an open-addressing unique-key map and set hashtables using robin-hood collision resolve.

This project is currently under construction and is in progress of being published.
The performance of the core hashtable implementation is approaching that of the excellent library https://github.com/martinus/unordered_dense, and in some aspects is even surpassing it.
However, the rhashtable project is still in its infancy, so the container API and feature set are incomplete, with only the bare minimum currently implemented.
